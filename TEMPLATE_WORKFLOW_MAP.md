# Starter Template Workflow Map

This file shows the node path for each starter template at a glance.

## Simple

- **Summarize & Rewrite**  
  `Input -> AI Summarize -> AI Rewrite -> Output`

- **Casual -> Formal**  
  `Input -> AI Rewrite(Formal) -> Output`

## Medium

- **Data Cleaner**  
  `Input -> Trim -> Lowercase -> Replace -> Output`

- **Blog Post Polisher**  
  `Raw Notes -> Trim -> AI Summarize -> AI Rewrite(Creative) -> Output`

- **Animated Pipeline Demo**  
  `Input -> Delay(1.5s) -> Uppercase -> Delay(1s) -> AI Summarize -> Output`

- **Dual Tone Comparison**  
  `Input -> AI Summarize -> [AI Rewrite(Casual), AI Rewrite(Persuasive)] -> [Output A, Output B]`

## Killer Demo Workflows

- **Content Creator Pipeline**  
  `Input -> Clean -> Rewrite(Casual) -> Summarize(Tweet) -> Custom(Hashtags) -> Output`  
  plus side branch: `Clean -> Rewrite(Persuasive)`

- **Study Assistant Flow**  
  `Study Notes -> Trim -> Lowercase -> [Summarize, Custom(Flashcards)] -> Custom(Quiz) -> Output`

- **Job Application Flow**  
  `Resume -> Clean -> Summarize -> [Rewrite(Professional), Custom(Cover Letter)] -> Translate(Spanish) -> Output`

## Advanced

- **Full Content Production Pipeline**  
  Main path: `Input -> Trim -> Lowercase -> Delay -> AI Summarize -> Rewrite(Professional) -> Output`  
  Extra branches:  
  - `Input -> Uppercase`  
  - `AI Summarize -> Rewrite(Casual)`
